LLM Injector 개인정보처리방침

시행일: 2026-10-06 / 최종 수정일: 2026-10-06

핵심 요약: LLM Injector의 메모·일정·대화 데이터는 사용자의 PC에만 저장됩니다. 외부 서버로 전송되는 것은 AI 답변 생성에 필요한 최소 정보(선택한 AI 모델에 보내는 질의 내용 및 API 키)에 한하며, 광고·판매 목적으로 개인정보를 제3자에게 제공하지 않습니다.

1. 수집하는 정보

  • 메모 및 일정: 사용자가 직접 입력한 메모, 이미지, 일정, 알람. PC 내 %APPDATA%\LLM_Injector에만 저장됩니다.
  • 대화 내용: AI와의 대화 기록. PC 내에만 저장됩니다.
  • API 키 및 자격 증명: 사용자가 직접 입력한 외부 AI 서비스 키(Gemini 등), Google 캘린더 OAuth 토큰. Windows DPAPI로 OS 수준 암호화되어 PC 내에만 저장됩니다.
  • 진단 정보: 오류 발생 시 로컬 로그 파일에만 기록되며, 개발자에게 자동 전송되지 않습니다.

2. 외부 전송 정보

  • 클라우드 AI 모델 사용 시: 사용자가 입력한 질문 텍스트가 선택한 AI 서비스 제공자(예: Google Gemini API)에게 전송되어 답변을 생성합니다. 이때 API 키로 본인 인증이 이루어집니다.
  • 로컬 AI 모델 사용 시: 데이터가 PC를 떠나지 않습니다. (Ollama 등 로컬 모델)
  • 웹 검색 사용 시: 검색어만 검색 서비스 제공자에게 전송됩니다.
  • 업데이트 확인(스토어 버전 제외): 버전 문자열만 업데이트 서버에 조회합니다. Microsoft Store 버전은 스토어가 업데이트를 관리하므로 별도 조회가 없습니다.

3. 정보의 보관 및 파기

  • 모든 사용자 데이터는 사용자의 PC에만 보관됩니다.
  • 앱 삭제 시 프로그램 파일이 제거되며, PC에 남는 데이터 폴더(%APPDATA%\LLM_Injector)는 사용자가 직접 삭제할 수 있습니다.
  • 메모·일정 삭제 시 앱 내에서 즉시 삭제되며, 관련 이미지 파일도 함께 정리됩니다.

4. 제3자 제공 및 위탁

  • 개인정보를 제3자에게 판매·대여하지 않습니다.
  • 위 2항의 AI 답변 생성 목적 외에는 외부 전송이 없으며, 별도의 수탁 업체가 없습니다.
  • Microsoft Store를 통한 배포·결제·업데이트는 Microsoft의 개인정보처리방침이 함께 적용됩니다.

5. 사용자의 권리
